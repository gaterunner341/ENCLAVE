ENCLAVE — asset inventory and assurance
=======================================

INSTALL
-------
1. Put ENCLAVE.exe anywhere you like (Desktop is fine).
2. Double-click it.
3. Your browser opens at http://127.0.0.1:8080

That's it. No Go, no installer, no admin rights, no database.
A black window appears — leave it open. Closing it stops the app.

FIRST TIME
----------
In the browser:

  1. Click "Enclaves" and add one.
     Identifier: CORP-CORE     Range: 10.12.0.0/16     Owner: your name

  2. Click "Import data" and upload a CSV export from any tool
     (Tenable, CrowdStrike, SCCM, ServiceNow, AD — whatever you have).

  3. It reads your column headers and fills in the mapping for you.
     Check it, name the source, pick what kind of tool it came from, Import.

  4. Overview now shows coverage per enclave. Conflicts shows where two
     tools disagree about the same machine.

NOTES
-----
- Data lives in the "enclave-data" folder next to the .exe.
  Back it up by copying that folder. Delete it to start over.
- From Excel, save as "CSV UTF-8 (Comma delimited)".
- Windows may warn about an unsigned app: More info > Run anyway.
- Nothing leaves your machine. It listens on localhost only and
  never connects out.
- There is no login yet, so don't put it on a shared server.

STOPPING IT
-----------
Close the black window.
