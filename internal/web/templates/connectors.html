What this changes

Without a connector ENCLAVE opens no sockets outward at all, which is most of why it is straightforward to run on a network that does not allow that.

With one on, it connects to the console you name, when you press one of the buttons here. It does not poll, it does not run on a timer, and it sends nothing anywhere else.

What it takes is the same .nessus export you would have downloaded by hand, read by the same code that reads an uploaded one. The connector fetches; it does not interpret.

From the command line

enclave tenable test
enclave tenable list
enclave tenable import 101 102
enclave tenable sync --since 30d

Which is what to put on a schedule if you want this to happen without somebody pressing a button.
