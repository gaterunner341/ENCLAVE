What this changes

With no connector switched on, ENCLAVE opens no sockets outward at all.

With one on, it connects to that console when you press a button here or run the command below. It does not poll, it does not run on a timer, and it sends nothing anywhere else.

What it takes is the same .nessus export you would have downloaded by hand, read by the same code that reads an uploaded one.

From the command line

enclave tenable test
enclave tenable list
enclave tenable sync --since 30d

Add --connector ID when more than one is switched on. This is what to put on a schedule if results should arrive without somebody pressing a button.
