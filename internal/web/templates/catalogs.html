The plain text format

An organisation's own framework is a text file, so it reviews as a readable diff rather than a wall of braces.

@id       acme-secure-build
@name     ACME Secure Build Standard
@version  2026.1
@profile  core = Core requirements
@profile  ext  = Extended requirements
@family   HD   = Hardening

HD-1    | Approved base image only   | core,ext
HD-1(1) | Image rebuilt monthly      | ext
HD-2    | Local administrator vaulted | core,ext

A CSV works too: give it id and title columns, and optionally family, profiles, statement and discussion.
