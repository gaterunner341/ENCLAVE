Upgrading to a new version

  1. Download a backup from the button above. One file, everything in it.
  2. Put the new build wherever you want it and start it.
  3. Open its Data page and restore the file.

The backup carries the enclaves, assets, findings, imports, control assessments and risk entries, along with any control catalogues and mapping tables you loaded. It is an ordinary zip: open it and the files inside are the same readable JSON that sits in the data folder.

Copying the whole {{$d.Dir}} folder to the new location does the same job. The backup file exists so you do not have to know that.

Why the version matters

The data folder records which layout wrote it. A build that understands that layout reads it directly. A newer build upgrades it on the way in.

An older build handed data from a newer one refuses to open it and says so, rather than reading half of it and writing back something neither version can use. The same check runs on a backup file before a single byte is written.

Other ways out

A backup is for moving ENCLAVE. To get the contents into something else, the exports are plain CSV and the API is plain JSON.
