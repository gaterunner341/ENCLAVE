Load a mapping

Loading a table re-checks every finding already imported, so evidence appears without re-importing anything.

The CSV format

Two columns: a key and the controls it maps to. Rows beginning with a hash set the table's metadata.

#name,Local crosswalk to our standard
#scheme,control
#target,acme-secure-build

key,controls
AC-2,"HD-2,HD-3"
CM-6,HD-1
SI-2,"HD-4,HD-5"

A control scheme is a crosswalk: it takes a finding that already resolved to a control in one framework and carries it into another. That is how a STIG result reaches a CIS safeguard without a per-rule table.
